# Regras do jogo

Esta pasta contém as regras normativas que definem a identidade e os limites de Noir 1974. Toda decisão, criação ou resolução de um problema do jogo deve ser auditada contra estas regras antes de ser aceita ou incorporada ao projeto.

As regras são literais e obrigatórias. Uma implementação conveniente, uma preferência estética ou uma decisão técnica não pode contrariá-las. Se uma proposta entrar em conflito com uma regra, ela deve ser revista para se adequar à regra. Uma regra só muda por alteração explícita e documentada nesta pasta; não pode ser contornada por ADR, roadmap, implementação ou convenção local.

## Auditoria obrigatória

Antes de aceitar uma decisão, funcionalidade, conteúdo, interface, asset ou solução:

1. Identificar as regras aplicáveis.
2. Verificar cada requisito da regra, sem presumir exceções.
3. Rejeitar ou revisar qualquer parte que viole uma regra.
4. Registrar a auditoria junto à proposta, PR ou documento quando houver processo de revisão.

Quando houver dúvida sobre conformidade, o item não está aprovado até que seja esclarecido ou ajustado. A auditoria não substitui os ADRs: regras definem limites obrigatórios; ADRs registram escolhas feitas dentro desses limites.
