# ADR 0002 — Jogo 100% web, HTML/CSS/JS, REST

- **Status:** Aceita
- **Data:** 2026-09-21
- **Supersede:** nenhum

## Contexto

O jogo precisa ser acessível no navegador, com cliente leve e servidor reconstruindo o mundo.

## Decisão

- O produto é 100% web.
- Frontend: HTML + CSS + JavaScript.
- Comunicação cliente–servidor: REST API.
- A API concreta ainda não é contrato; só a forma (REST) está fechada.

## Consequências

- Sem cliente nativo na versão inicial.
- Sem protocolo de tempo real como requisito de arquitetura.
- Frontend vive em `apps/web`; API em `apps/api`.
