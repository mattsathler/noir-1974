# apps/web

Cliente web de Noir 1974.

Stack pretendida: HTML, CSS e JavaScript. Consome a REST API em `apps/api`.

O navegador solicita estado; o servidor reconstrói e devolve o que o jogador pode ver. O cliente não decide o mundo, os casos nem as mutations.

Implementação começa no ciclo correspondente do [roadmap](../../docs/roadmap/README.md). Até lá, esta pasta existe para marcar o lugar do frontend no monorepo.
